# 📅 我的日历 - 每日任务管理

一个纯前端、可完全离线使用的日历任务管理网页。双击 `calendar.html` 即可在浏览器中打开使用，无需联网、无需安装任何东西。

## ✨ 功能

- **月历视图** — 前后翻月、一键回到今天
- **每日任务** — 点击任意日期添加任务，可设置时间
- **完成勾选** — 点击勾选框标记完成，已完成任务自动划线
- **删除任务** — 一键删除不需要的任务
- **统计面板** — 今日完成数、本月完成数、有任务的日期数
- **本地存储** — 所有数据保存在浏览器 localStorage 中，关闭页面不会丢失
- **个性化定制** — 主题色 / 深色模式 / 字号 / 布局密度 / 周起始日，均可自定义并保存
- **任务分类** — 自带工作/生活/学习等分类，可增删改、自定义颜色，支持按分类筛选
- **⏰ 到点提醒** — 给任务设置时间后，到点自动弹提示条 + 提示音；开启系统通知后页面在后台也能收到系统弹窗；超时未完成任务会标红色「已超时」

## 🚀 使用方法

1. 下载 `calendar.html` 到本地
2. 用任意现代浏览器（Chrome / Edge / Safari / Firefox）打开
3. 开始添加你的每日计划

> ⚠️ 注意：数据按浏览器隔离存储。请固定使用同一个浏览器打开，清除浏览器数据会同时清除任务记录。

## 💻 技术说明

- 单文件 HTML 应用（HTML + CSS + JavaScript，无任何依赖）
- 数据持久化使用 localStorage
- 响应式布局，支持手机和电脑
